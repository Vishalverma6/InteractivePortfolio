Plant Portfolio Website 🌿

An interactive plant portfolio website that allows users to explore different indoor and outdoor plants through a modern and visually appealing interface. The platform showcases plant collections, popular products, customer reviews, and also allows users to purchase plants online.

Features ✨
Modern and responsive UI
Explore different types of plants
Product showcase section
Customer review section
Smooth user experience
Mobile responsive design
Buy plants online feature



Tech Stack 🚀
React.js
Tailwind CSS
JavaScript
Vite



Installation ⚙️

Clone the repository: git clone <repository-link>

Navigate to project folder:cd project-name

Start development server:npm run dev
